A loading-screen tip in under 200 characters: the build isn't stuck, it's just
thinking about what you did. Go drink water. It will still be thinking when
you get back.

## Entry

`main.ts` writes the tip to `/output/entry.txt`:

> Tip: the build isn't stuck, it's just thinking about what you did. Go drink water. It will still be thinking when you get back.

## Run

```sh
node main.ts
```
